About N42 Gateway

{{< /blocks/cover >}} {{< blocks/lead color="dark" >}}

N42 Gateway watches Ingress and Gateway resources from a Kubernetes cluster, and configures a HAProxy instance which will route incoming requests to the pods. Updates to the cluster state is automatically applied to the HAProxy instance.

N42 Gateway is the continuation of the HAProxy Ingress project, renamed in 2026 to better distinguish the project from products and services offered by HAProxy Technologies SAS.

{{< /blocks/lead >}} {{< blocks/lead color="primary" >}}

HAProxy® is a fast and reliable TCP and HTTP reverse proxy and load balancer.
N42 Gateway carefully build an optimized HAProxy configuration, which allows thousands of requests per second per proxy, despite the size of your cluster, with a very low latency.

Kubernetes is a system which automates the deployment of containerized applications.
N42 Gateway uses deployment and exposing spec from the Kubernetes cluster to build routing rules, allowing incoming requests from an external network to the in-cluster applications.
